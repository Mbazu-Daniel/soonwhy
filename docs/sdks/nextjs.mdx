# Next.js

```bash
pnpm add @soonwhy/nextjs
```

```ts
import { initNextjs } from '@soonwhy/nextjs';
export function register() {
  initNextjs({ apiKey: process.env.SOONWHY_API_KEY!, serviceName: 'nextjs-app' });
}
```

Keep server credentials server-only. Use `getBrowserConfig()` for browser configuration when needed.
