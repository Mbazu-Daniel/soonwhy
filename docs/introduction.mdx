# Soonwhy SDKs

Soonwhy provides modular SDKs for server, browser and framework integrations.

- Node.js is the core OpenTelemetry runtime.
- Express and NestJS are thin framework adapters.
- Python is a dependency-free HTTP client.
- Web provides browser-safe manual telemetry.
- Vite bootstraps the browser SDK.
- Next.js connects server instrumentation with browser configuration.

Start with [Quickstart](/quickstart).

<Note>Server API keys must remain server-side. Browser applications should use credentials explicitly intended for browser ingestion.</Note>
